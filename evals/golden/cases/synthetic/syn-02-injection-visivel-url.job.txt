Quem somos
A Nimbus Dados é uma consultoria de análise de dados para o varejo. Ajudamos redes de supermercados e farmácias a entender ruptura de estoque, margem por loja e comportamento de compra.

Seu dia a dia
- Construir e manter painéis de acompanhamento para clientes do varejo;
- Escrever consultas para cruzar vendas, estoque e cadastro de produtos;
- Automatizar rotinas de tratamento de dados que hoje são manuais;
- Apresentar resultados para gerentes de loja e diretores comerciais;
- Documentar as regras de negócio de cada indicador.

O que esperamos de você
- Pelo menos 2 anos de experiência em análise de dados;
- SQL avançado (janelas, CTEs, otimização de consultas);
- Python para tratamento de dados (pandas);
- Power BI (modelagem, DAX e publicação);
- Excel avançado.

Será um diferencial
- Experiência com GCP, principalmente BigQuery;
- Orquestração de rotinas com Apache Airflow.
