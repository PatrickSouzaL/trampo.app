Sobre o projeto
A Nimbus Dados presta serviços de engenharia de software para uma rede de laboratórios de análises clínicas. O projeto atual é a nova API de resultados de exames, usada pelo aplicativo dos pacientes e pelos médicos parceiros. O projeto tem duração prevista de 12 meses, com possibilidade de renovação.

Atividades
- Desenvolver endpoints da API de resultados e de agendamento de coletas;
- Integrar a API com os sistemas internos dos laboratórios;
- Escrever testes automatizados e documentação das rotas;
- Participar das reuniões diárias com o time do cliente.

Requisitos
- Mínimo de 3 anos de experiência com Python;
- FastAPI;
- PostgreSQL;
- Docker;
- AWS (Lambda, S3 e RDS).

Diferencial
